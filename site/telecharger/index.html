À la première ouverture

Ton système va prévenir qu'il ne reconnaît pas le développeur. C'est normal : faire signer un logiciel coûte une centaine de dollars par an chez Apple et autant chez Microsoft, et ce projet est donné. Le logiciel n'est pas moins sûr pour autant — il est ouvert, et tu peux en lire tout le code. Voici comment passer l'avertissement, une seule fois.

Sur Mac

Ouvre le fichier .dmg et glisse Bingo Studio dans Applications.

Au premier lancement, un message dit qu'Apple n'a pas pu vérifier l'application. Ferme-le, puis :

  1. Menu → Réglages du système
  2. Confidentialité et sécurité
  3. Descends jusqu'au message sur Bingo Studio, puis Ouvrir quand même

Sur les Mac plus anciens, un clic droit sur l'application puis Ouvrir suffit.

Sur Windows

Lance le fichier .exe. L'installation ne demande pas les droits administrateur.

Windows affichera « Windows a protégé votre ordinateur » :

  1. Clique sur Informations complémentaires
  2. Puis sur Exécuter quand même

Un raccourci est créé sur le bureau et dans le menu Démarrer.

Vérifier le fichier téléchargé

Facultatif, mais c'est la preuve que le fichier reçu est bien celui publié. Compare l'empreinte de ton fichier à celle-ci.

  • Mac — dans le Terminal : shasum -a 256 ~/Downloads/BingoStudio-1.1.0-mac.dmg
  • Windows — dans PowerShell : Get-FileHash BingoStudio-1.1.0-windows.exe
