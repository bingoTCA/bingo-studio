À la première ouverture

Le système préviendra peut-être que le développeur n'est pas identifié. C'est normal pour un logiciel offert gratuitement, sans certificat payant.

  • Sur Mac — clic droit sur l'application, puis Ouvrir. Une seule fois.
  • Sur Windows — Informations complémentaires, puis Exécuter quand même.

Et ensuite

Deux fenêtres s'ouvrent : la régie pour toi, l'antenne pour le téléviseur. Le mode d'emploi te guide en six étapes.
